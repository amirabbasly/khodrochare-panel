# پنل مشاهده‌ای خودرو چاره

پنل فارسی و راست‌به‌چپ با نقشه Leaflet، فیلتر استان/نقش، وضعیت GPS، فهرست مشتریان و امدادگران، درخواست‌ها بر اساس خدمت و وضعیت، جزئیات هزینه قطعات و پرداخت، نمودار ۳۰ روز درآمد اپلیکیشن و امدادگران و فیلتر امدادگر. داده ساختگی در محصول وجود ندارد. اطلاعات هر ۵ ثانیه تازه می‌شوند؛ مکان فقط در صورت اجازه کاربر و هنگام باز بودن اپ دریافت می‌شود. GPS قدیمی کم‌رنگ و با زمان دریافت مشخص است.

## اجرا

ابتدا بک‌اند جدید را دیپلوی کنید؛ migration `202610240001_monitoring` خودکار اجرا می‌شود. در `.env` بک‌اند باید `ADMIN_USERNAME` و `ADMIN_PASSWORD_HASH` تنظیم باشند. برای ساخت امن آن‌ها بدون نیاز به دیتابیس:

```sh
node scripts/setup-admin.js
```

این دستور در پوشه **بک‌اند** اجرا می‌شود، تنظیمات قبلی را نگه می‌دارد و رمز تصادفی را در فایل محلی و gitignored با نام `ADMIN-CREDENTIALS.txt` می‌نویسد. در این محیط فایل از قبل ساخته شده است. رمز خام در کلاینت قرار نمی‌گیرد؛ بک‌اند فقط hash رمز را نگه می‌دارد.

در پوشه پنل:

```sh
npm ci
# .env.local: ADMIN_API_BASE_URL=https://api.khodrochare.ir/api/v1
npm run build
npm start
```

متغیر `ADMIN_API_BASE_URL` فقط سمت سرور است. پنل به Next.js server نیاز دارد و خروجی static نیست. دامنه پنل را با HTTPS سرو کنید. مرورگر با `/api/admin` روی دامنه خود پنل ارتباط دارد؛ Next.js درخواست را به بک‌اند منتقل می‌کند و نشست مستقل ۸ ساعته را در کوکی HttpOnly نگه می‌دارد. ورود و خروج، تنها عملیات نوشتنی پنل‌اند؛ API واسط فقط دریافت نمای کلی و ورود/خروج را می‌پذیرد. تأیید واریز یا تغییر کاربران/درخواست‌ها از این پنل امکان‌پذیر نیست.

## دامنه آمار

- شمارنده‌های کل و درآمد دفتر مالی از کل دیتابیس‌اند. جزئیات فهرست‌ها به ۲۰۰۰ حساب و درخواست اخیر محدودند و این محدودیت در رابط نمایش داده می‌شود.
- نمودار از `DriverEarning` است: خدمت تکمیل‌شده و پرداخت تأییدشده. واریزهای منتظر بررسی جدا نمایش داده می‌شوند. سهم امدادگر به معنی انتقال بانکی به حساب او نیست.
- فیلتر استان روی نقشه و فهرست‌ها اعمال می‌شود؛ نمودار درآمد فیلتر امدادگر مستقل دارد. استان نامعلوم صریح نمایش داده می‌شود. نام استان از سرویس reverse geocoding دریافت و در سرور کش می‌شود.
- زمان‌ها به وقت تهران و مبالغ به تومان‌اند. در نبود شبکه یا GPS، پنل موقعیت زنده اختراع نمی‌کند. گردآوری موقعیت در پس‌زمینه سیستم‌عامل یا پس از بستن اپ تضمین نمی‌شود.

تست‌های مرورگر در `../khodrochare-app/tests/admin.spec.ts` و تست‌های دسترسی در `../khodrochare-backend/test/monitoring.test.js` هستند. تست یکپارچه دیتابیس در این محیط به علت نبود Docker اجرا نشده است.
